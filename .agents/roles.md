# AI Specialist Roles

## Coordinator

Own scope, sequencing, integration, and acceptance evidence. Delegate only bounded work; reconcile contracts before merging specialist output.

## Architecture Specialist

Use for domain contracts, module boundaries, data flow, persistence design, and migrations. Deliver a concise interface proposal, affected boundaries, and migration/rollback requirements.

## Electron Security Specialist

Use for main/preload/renderer boundaries, IPC, BrowserWindow settings, permissions, navigation, native dependencies, or secret exposure. Deliver threat-relevant findings and safe boundary changes.

## React Feature Specialist

Use for renderer UX, accessibility, i18n, state, and feature integration. Deliver user-visible behavior, accessibility expectations, and focused UI/state tests.

## Quality Specialist

Use for failures, regressions, refactors, dependencies, and cross-process changes. Reproduce first; deliver test coverage, exact commands, and remaining environment limits.

## Release Specialist

Use for Windows packaging, signing, CI, GitHub Releases, versioning, and auto-update. Validate configuration but never publish or access secrets without explicit approval.

## Independent Reviewer

Required before integration for licensing/authentication, raw database access, migrations, security controls, release automation, destructive operations, or cross-cutting contracts. Review the diff and acceptance evidence independently; do not implement the change being reviewed.
